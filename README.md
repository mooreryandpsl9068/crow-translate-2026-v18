## Overview

Crow Translate 2026 is a Windows desktop application for translation, multilingual communication, and localization work. Its interface provides a practical way to translate text, move between languages, and organize translation tasks within one app.

Version 18 brings together several translation methods for different working styles. Users can process content locally, connect supported API providers, or translate groups of documents in batches, making the software suitable for both quick translations and broader content workflows.

## Key Features

- Translate content across multiple languages
- Connect OpenAI and Claude APIs for cloud-assisted translation
- Detect the input language automatically
- Build custom glossaries for reliable terminology and localization
- Work in offline mode when an internet connection is unavailable
- Process multiple documents through batch translation
- Save translated results as PDF, CSV, or JSON files
- Enter text through voice input for hands-free translation

## Using the Application

Choose the source and destination languages first. You can then type or paste text, import documents, or provide spoken input. Depending on the task, translation can run through local processing or an API-connected provider.

The application can be used to:

- Translate individual snippets as needed
- Submit several documents to a batch translation task
- Apply glossary terms to preserve consistent wording
- Let the application identify an unknown source language
- Export completed translations as PDF, CSV, or JSON
- Record voice input and translate the captured text

A typical session looks like this:

1. Launch the application.
2. Choose the desired translation mode.
3. Provide text, a document, or voice input.
4. Check the detected source language and resulting translation.
